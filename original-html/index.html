WVN // web audio toys

self-contained, no build step, stock nodes only
SERENITY
Ambient random generator — a slow pentatonic pad chord, wandering root, and random FM chimes over a feedback-delay wash.
SHIFT
Bode frequency shifter built from stock BiquadFilterNodes realizing a Hilbert transformer, plus a phase-locked quadrature LO.
CAYLEY II
8-voice octonion harmonic sequencer, cross-mixed by a spinning unit-octonion rotor, with ghost/memory/swap/stasis intrusions.
Each toy has a THEME row under its header (VOID / DUSK / NEON / CANDY / FUNHOUSE).
